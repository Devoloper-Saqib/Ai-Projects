# 🧠 AI Website Builder

This is a fully functional AI-powered website generator built with **Node.js**, **HTML**, **CSS**, and **JavaScript**. It allows users to enter a prompt and generates a website preview using AI-generated code.

---

## 🚀 Features

- 🔹 User-friendly input system
- 🔹 Backend built with Express and Node.js
- 🔹 AI-generated HTML/CSS output
- 🔹 Displays generated code with syntax highlighting
- 🔹 Fully responsive output website preview

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **AI Integration:** (e.g., OpenAI / HuggingFace API)
- **Syntax Highlighting:** Highlight.js

## 💻 How to Run Locally

```bash
# Clone the repo
git clone https://github.com/Devoloper-Saqib/Ai-Projects.git

# Go to the folder
cd Ai-Projects

# Install dependencies
npm install

# Start the server
node server.js
Now visit 👉 http://localhost:3000 in your browser.
